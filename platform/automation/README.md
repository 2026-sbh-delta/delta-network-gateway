# VM Deployment Automation

Terraform으로 준비된 고객 VM에 앱을 배포하는 자동화를 둔다. 현재 실행 가능한 playbook·스크립트는 없다.

Ansible 기반의 공통 배포 작업을 제안한다.

1. 관리 접속·Docker·이미지 다운로드 가능 여부를 확인한다.
2. 검사한 이미지 digest와 실행 설정으로 후보 버전을 실행한다.
3. 헬스 체크 후 합의된 LB 방식으로 요청을 전환하고 재검사한다.
4. 실패 시 기존 버전을 유지하거나 복구하고 결과를 Worker에 반환한다.

AWS EIC·GCP IAP·온프레미스 SSH 접속 차이는 환경별 설정으로 분리한다. 실제 LB·포트·VM 배치는 추가 결정 사항이다.

인프라 생성은 기존 `terraform/`, OS·Docker·수집 도구 설치는 인프라팀의 기본 VM 구성이 담당한다. 이 디렉터리는 고객 앱 배포를 소유하며, 앱 복구로 DB 변경까지 복구됐다고 처리하지 않는다.
