# Platform Backend

API와 Worker는 공통 Python 패키지 `delta_platform`을 사용하고 별도 프로세스로 실행한다. 현재는 디렉터리만 준비했으며 실행 명령과 패키지 의존성은 아직 없다.

| 모듈 | 책임 |
| --- | --- |
| `api/` | 인증·프로젝트 권한, 입력 검증, 작업 접수·조회 |
| `worker/` | 작업 선점·실행·재개, 외부 작업 상태 확인, 취소·시간 초과 |
| `core/` | 서비스 등록, 작업·단계·이벤트, 영속 상태와 중복 실행 방지 |
| `adapters/` | GitHub·CI, Terraform 결과, ECS 검사 도구, VM 배포, 관측 조회 |

FastAPI와 PostgreSQL을 제안한다. 플랫폼 DB는 이전 대상인 고객 DB와 분리한다. 인증 공급자는 초기 API 설계에서 확정한다.

- API 요청 안에서 빌드·Terraform·VM 배포를 끝까지 실행하지 않는다.
- 작업 상태와 외부 실행 ID를 저장한다. Worker 재시작 시 실제 외부 상태를 확인하고 재개한다.
- 프로젝트 권한을 모든 조회·실행에 적용한다. 미연결 어댑터가 성공을 모사하지 않도록 한다.
- `tests/`에는 권한 격리, 실제 DB의 상태 보존, 중복 요청·재시작 등을 검증하는 테스트를 둔다. 아직 작성·실행하지 않았다.
