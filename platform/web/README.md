# 플랫폼 웹

고정 계정 로그인과 서비스 개요·빌드/검사·이전 계획·모니터링을 제공한다. React·TypeScript·Vite를 사용하고 `package-lock.json`으로 버전을 고정한다. Node.js 24를 사용한다.

```bash
npm ci
npm run build
```

API가 `dist/`를 같은 origin에서 제공한다. 전체 실행은 [플랫폼 안내](../README.md)를 따른다. 별도 Vite 개발 서버가 필요하면 백엔드 `PLATFORM_PUBLIC_ORIGIN=http://127.0.0.1:5173`으로 설정하고 `npm run dev`를 실행한다. `/api`는 8088의 API로 전달한다.

## 발표 화면과 탐색

- 데스크톱·모바일 모두 왼쪽 상단 메뉴 버튼으로 서랍을 연다. 기본은 닫힌 상태이며 본문이 전체 너비를 사용한다. Escape/닫기/배경 클릭/메뉴 선택으로 닫고, 열린 동안 키보드 포커스와 배경 스크롤을 제한한다.
- 서비스 개요 → 빌드·검사 → 이전 계획 → 모니터링 순서로 설명한다. 서비스 개요의 다음 작업 카드로 각 화면에 바로 이동할 수 있다.
- 빌드·검사는 이미지 빌드 / 실행 확인 / 보안 검사로 나뉜다. 커밋·소스 기록·등록 정보·이력은 필요할 때 펼친다.
- `#/overview/{service_id}`, `#/build/{service_id}`, `#/migration/{service_id}`, `#/monitoring/{service_id}`로 현재 서비스와 화면을 보존한다. 새로고침과 브라우저 뒤로가기가 동작한다. 선택한 서비스는 모니터링으로도 전달된다.
- `AppShell`은 인증과 독립된 화면 틀이며 계정 영역을 선택적으로 받는다. 현재 로그인과 API 인증은 유지한다. 후속 로그인 제거는 프론트만 우회하지 않고 API 인증 정책과 함께 변경해야 한다.

## 화면 원칙

- 본문은 16px, 보조 정보는 14px 이상을 사용한다. 공통 글자 크기와 색상은 `style.css`의 CSS 변수로 관리하며 밝은 본문과 짙은 글자, 파란 주요 동작을 사용한다.
- 카드 제목과 도구 모음은 좁은 화면에서 줄바꿈한다. 버튼은 최소 높이 44px를 사용하고 키보드 포커스를 표시한다.
- 배포 완료 앱의 개요는 AWS → GCP → On-Premise 순서의 환경 카드와 `이관 진행`/`모니터링` 이동 버튼을 표시한다. 카드는 테두리와 상단 색상 효과 없이 연한 주황/파랑/회색 배경과 로컬 SVG 로고를 사용한다. 진행 중 앱은 자동 배포 진행을, 기존 단일 서비스는 기존 개요와 수동 작업을 유지한다. 배포 완료를 조회하면 새로고침 없이 환경 카드로 전환한다.
- `이관 진행`은 Font Awesome Free의 양방향 화살표, `모니터링`은 라인 차트 아이콘을 글자 앞에 표시한다. SVG는 로컬 코드에 포함하고 출처와 라이선스 고지는 `public/third-party-notices/fontawesome.txt`로 제공한다.
- 배포 환경 카드와 자동 배포 진행의 주소 안내 문단은 표시하지 않는다. 주소 데이터와 API, 배포 상태 및 계속 진행 동작은 유지한다.
- 실제 API가 반환한 서비스·검사 결과만 표시한다.
- 소스 검사의 `succeeded`는 **소스 확인 완료**다. 앱의 배포 상태 `succeeded`와 구분하며 소스 확인을 빌드/배포 성공으로 표시하지 않는다.
- 진행 중인 검사와 앱 배포 진행은 3초 간격으로 조회한다. 배포 환경 목록은 10초 간격이며 화면을 떠나면 조회를 취소한다.
- 쓰기 요청에는 CSRF 토큰을 보내고, 중복 클릭·통신 재시도에는 같은 요청 키를 사용한다.
- 비밀번호·세션 토큰을 localStorage에 저장하지 않는다.

## 브라우저 시험

시험용 PostgreSQL을 준비하고 웹을 빌드한 뒤 `npm run test:e2e`를 실행한다. Playwright가 시험용 API·별도 Worker를 기동한다. GitHub 응답은 fixture이며 DB와 실행 상태는 실제로 저장한다. 로그인·성공·실패·새로고침·로그아웃·모바일 화면을 확인한다.

`npm run format:check`로 코드 형식을 확인한다. 캡처·시험 결과·빌드 출력은 Git에서 제외한다.

DB 없이 탐색·계획·모니터링 화면을 검사하려면 `npx playwright test --config=playwright.fixture.config.ts`를 실행한다. 이 시험은 API를 브라우저 fixture로 대체하며 실제 운영 결과를 만들지 않는다. 발표용 탐색 시험은 데스크톱·모바일 캡처도 남긴다.

## 프로젝트 대시보드

모니터링은 현재 선택한 서비스의 대시보드다. 화면 안에 서비스 선택 드롭다운을 중복 표시하지 않는다. 서비스 선택 전 모니터링에 진입하면 서비스 목록에서 대상을 선택한다. 환경은 탭, 기간은 버튼으로 전환하며 데이터 없음·지연·조회 오류를 구분한다. 환경 미연결 시에도 지표 구조와 연결 안내를 표시하고 새로고침을 지원한다.
