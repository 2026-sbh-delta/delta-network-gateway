# Platform Contracts

플랫폼과 팀의 도구가 주고받을 계약을 관리한다. U1 HTTP·DB 계약은 구현했으며, 아래 후속 배포·도구 연동 계약은 초안이다.

현재 구현 대상인 U1은 [HTTP 계약](u1-http.md)과 [DB 구조](u1-data.md)를 따른다. 고정 로그인·공통 작업 공간이며 개인별 프로젝트 권한은 제공하지 않는다.

| 계약 | 핵심 정보 | 연결 |
| --- | --- | --- |
| 서비스 등록 | 서비스 ID, 공개 저장소, 브랜치, 빌드 경로, 포트·헬스 체크 | 웹 ↔ API |
| 배포 작업 | 작업 ID, 확정된 커밋, 이미지 digest, 목적지, 단계·외부 실행 ID | API ↔ Worker |
| 인프라 요청 | 서비스·환경, CSP·리전, VM 크기 등급, 네트워크, 포트, 기본 이미지 버전 | Worker → Terraform 실행 작업 |
| 인프라 결과 | 계정·프로젝트, VM ID, 사설 IP, 리전·존, CPU, 관리 접속 방식, 저장소 주소 | Terraform 출력 → Worker |
| 검사 | 플랫폼/도구 실행 ID, 검사한 이미지, 결과·증거 참조 | Worker ↔ 검사 도구 |
| VM 배포 | 대상 VM, 검증한 digest, 실행 설정·비밀값 참조, 헬스 체크 | Worker ↔ 배포 자동화 |

Terraform 전체 state를 웹에 전달하지 않는다. 비밀값은 실제 값 대신 참조를 담는다. 공급자별 접속 정보는 구분하고 계약 확정 후 버전을 부여한다.

외부 도구가 만든 실행 ID와 플랫폼 작업 ID를 연결해 기록한다. 두 ID가 같다고 가정하지 않는다.

- [스테이징 도구](../../docs/ai-dlc/staging-tool.md): 현재 작업 트리에 구현이 미병합이다. 최신 결정인 공개 ALB·스캐너 접근 제한과 문서의 과거 internal ALB 설명을 구분한다.
- [DAST API](../../services/delta-dast/docs/API.md): 로컬 토큰 흐름은 플랫폼 사용자 인증이 아니다. 서비스 간 인증·호출 범위는 연동 시 설계한다.
